# MD Converter Korean 🇰🇷

한글 깨짐 없는 마크다운 변환기 - Markdown converter with perfect Korean support

## 📌 Features

- ✅ **한글 완벽 지원** - UTF-8 인코딩으로 한글 깨짐 없음
- 📄 **다양한 변환 포맷**
  - HTML (styled/plain)
  - PDF (한글 폰트 포함)
  - Word (DOCX)
  - Excel (테이블만)
  - Plain Text
